# 🎲 Números da Sorte - Jogo de Adivinhação em React

O Números da Sorte é um jogo interativo de adivinhação desenvolvido em React. O projeto foi criado para proporcionar uma experiência divertida e dinâmica, unindo lógica de programação front-end com uma interface limpa e responsiva.

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias e ferramentas:

- **React:** Biblioteca JavaScript para construção da interface de usuário e gerenciamento de estado.
- **Vite:** Ferramenta de build rápida e moderna para o ambiente de desenvolvimento front-end.
- **CSS3 / Estilização:** Design focado em usabilidade e interatividade.
- **Git & GitHub:** Controle de versão e gerenciamento do código-fonte.

---

## 📝 Funcionalidades

A aplicação oferece os seguintes recursos:

- **Mecânica de Adivinhação:** Sistema interativo onde o usuário tenta adivinhar um número gerado aleatoriamente.
- **Feedback em Tempo Real:** Dicas visuais informando se o palpite está alto, baixo ou correto.
- **Contador de Tentativas:** Acompanhamento do desempenho do jogador a cada rodada.

---

## 🛠️ Configuração e Execução

Pré-requisitos:
- Node.js versão 16 ou superior instalado na máquina.
- npm ou yarn como gerenciador de pacotes.

Instalação:

1. Clone o repositório:
   ```bash
   git clone [https://github.com/Lucasluvn/Numeros-da-Sorte.git](https://github.com/Lucasluvn/Numeros-da-Sorte.git)

   Acesse a pasta do projeto:

2. acesse o projeto
   Bash
   cd Numeros-da-Sorte

3. Instale as dependências:
   Bash
   npm install
4. Rodando a aplicação:

  Ambiente de desenvolvimento:
  Bash
  npm run dev

5. Abra o navegador no endereço fornecido pelo Vite (geralmente http://localhost:5173)
